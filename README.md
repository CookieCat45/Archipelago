# TF2 Archipelago Setup
1. Navigate to your Team Fortress 2 installation's `tf` folder. Merge the `cfg` folder from `tf2-archipelago-cfg.zip` into `tf/cfg`.
2. In your Steam library, right click on Team Fortress 2 and click Properties. In the Launch Options section, add the following:   
`-usercon -console +rcon_password pwd`   
"pwd" can be whatever you prefer.



# TF2 Archipelago Connection Steps
1. After moving `tf2.apworld` into the `custom_worlds` folder in your Archipelago installation, run the Archipelago Launcher. Run the Team Fortress 2 client from the launcher.
2. Connect to the Archipelago server. After doing so, instructions will be displayed on how to connect the client to TF2 via RCON.
